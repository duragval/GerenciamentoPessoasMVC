Gerenciamento de Pessoas

Aplicação web desenvolvida em ASP.NET Core MVC para gerenciamento de pessoas, utilizando Entity Framework Core, SQL Server e ASP.NET Core Identity.

No seu caso, essa lista já mostra bastante coisa: C#, .NET, ASP.NET Core MVC, Razor, EF Core, SQL Server, Identity, Bootstrap, JavaScript, jQuery, Injecao de Dependencia, HTML, CSS

Contem:

- Cadastro de pessoas
- Listagem de pessoas
- Edição de pessoas
- Exclusão de pessoas
- Visualização dos detalhes
- Busca de pessoas
- Autenticação de usuários
- Cadastro de usuários
- Login e logout
- Controle de acesso por Roles

Tecnologias utilizadas:

- Back-end

- C# — linguagem principal utilizada no desenvolvimento da aplicação.
- .NET — plataforma utilizada para execução e desenvolvimento da aplicação.
- ASP.NET Core MVC — framework utilizado para construção da aplicação web seguindo o padrão Model-View-Controller.
- Entity Framework Core — ORM utilizado para realizar o mapeamento entre as classes C# e o banco de dados.
- ASP.NET Core Identity — framework utilizado para autenticação, gerenciamento de usuários e controle de acesso.
- Razor Pages — utilizadas principalmente nas páginas de autenticação do ASP.NET Core Identity.
- Dependency Injection — utilizada para gerenciamento e injeção das dependências da aplicação.

- Banco de dados

- SQL Server — banco de dados utilizado pela aplicação.
- SQL Server Express — ambiente utilizado para desenvolvimento local.
- Entity Framework Core Migrations — utilizadas para criação e atualização da estrutura do banco de dados.

- Front-end

- HTML5 — utilizado na estruturação das páginas.
- CSS3 — utilizado na estilização da aplicação.
- Bootstrap — framework CSS utilizado para construção da interface, componentes, formulários, tabelas, modais e responsividade.
- Bootstrap Icons — utilizado para os ícones da interface.
- JavaScript — utilizado para comportamentos e interações no lado do cliente.
- jQuery — biblioteca JavaScript utilizada em funcionalidades da aplicação.

Autenticação e autorização

O projeto utiliza o ASP.NET Core Identity para gerenciamento de usuários.

Os recursos implementados são:

- Login
- Logout
- Cadastro de usuários
- Gerenciamento de contas
- Autenticação de usuários
- Autorização baseada em Roles
- Controle de acesso para usuários: administradores e operadores
- Integração com Entity Framework Core
